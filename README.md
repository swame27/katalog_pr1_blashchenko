# Каталог произведений искусства

## Назначение
Приложение предназначено для систематизации и хранения информации о произведениях искусства: живописи, скульптуре, графике и других формах. Сервис позволяет вести структурированный каталог с привязкой произведений к авторам, категориям (жанрам, направлениям) и коллекциям, а также искать и просматривать произведения по различным критериям.

## Целевая аудитория
- сотрудники музеев, галерей и выставочных пространств, ведущие учёт экспонатов;
- искусствоведы и исследователи, работающие с систематизацией произведений;
- частные коллекционеры, каталогизирующие личные собрания;
- пользователи, интересующиеся искусством и желающие вести персональный каталог понравившихся произведений.

## Предметная область
Учёт и систематизация произведений искусства: каждое произведение относится к одному автору, принадлежит одной или нескольким категориям (жанр, стиль, направление) и может входить в состав коллекции (музейной, тематической или частной). Предметная область охватывает хранение метаданных о произведениях (название, год создания, техника исполнения, описание) и организацию их в структурированные группы.

## Основные сущности
- **Произведение** — конкретный объект искусства (название, автор, год создания, техника, описание, категория)
- **Автор** — создатель произведения (имя, годы жизни, страна, биография)
- **Категория** — жанр или направление искусства (живопись, скульптура, графика, импрессионизм и т.д.)
- **Коллекция** — тематическое или организационное объединение произведений (например, «Постоянная экспозиция», «Личная коллекция Иванова»)

## Основные функции
- добавление, просмотр, изменение и удаление произведений искусства
- ведение справочника авторов с биографическими данными
- группировка произведений по категориям
- объединение произведений в коллекции
- поиск произведений по названию, автору или категории
- фильтрация и сортировка каталога по различным параметрам

## План развития
На следующих этапах планируется:
- разработка веб-приложения на Django;
- подключение базы данных для хранения каталога;
- реализация пользователей (администраторов каталога, обычных посетителей) с разными правами доступа;
- разработка REST API для доступа к каталогу извне;
- контейнеризация приложения с помощью Docker;
- настройка CI/CD для автоматической сборки и развёртывания.
